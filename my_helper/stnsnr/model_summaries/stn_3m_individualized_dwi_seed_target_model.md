# STN 3m Individualized DWI Seed-Target Model

## Research Question

Do patient-specific DWI seed-target connectivity features from STN predict STN-only 3-month clinical outcome?

This is a seed-target / fiber-derived target-level model using individualized DWI tractography. It tests whether the STN target pattern seen in normative connectomes is present in each patient's own tractography.

## Endpoint

Primary endpoint:

```text
Y_STN3m = raw STN-only 3-month clinical score
```

Primary covariate:

```text
Y_Preop = raw preoperative clinical score
```

## Inputs

- Individualized DWI tractography from the imported DWI cohort.
- DWI registration outputs described in `dwi_registration_technical_details.md`.
- STN seed and target masks projected into patient DWI space.
- STN-only 3-month stimulation exposure maps or e-field-like proxy maps projected into DWI space.
- Raw clinical scores from `subject_effect_origin.xlsx`.

## Feature Construction

For patient `i`, side `h`, and target `k`, define individualized streamlines:

```text
G_ind_STN(i,k,h) = patient i streamlines connecting same-side STN seed to target P(k,h)
```

Side-specific target connectivity:

```text
C_ind_STN(i,h,k) =
  sum_j max exposure along patient streamline j
  / (number of streamlines in G_ind_STN(i,k,h) + lambda)
```

Patient-level bilateral feature:

```text
C_ind_STN_bilat(i,k) =
  (C_ind_STN(i,L,k) + C_ind_STN(i,R,k)) / 2
```

Run target coverage QC before modeling. A target should be interpreted only if bilateral streamlines are usable in enough patients, with `12/16` as the preferred rule and `13/16` as a stricter sensitivity rule.

## Statistical Model

Preferred model:

```text
normative-guided individualized DWI
```

Use normative connectome training folds to determine `S_STN` and `w_STN,k`, then compute individualized DWI score:

```text
STNTargetScore_ind_norm_i =
  sum_{k in S_STN_norm} w_STN,k_norm * Z(C_ind_STN_bilat(i,k))
  / sum_{k in S_STN_norm} abs(w_STN,k_norm)
```

Final model:

```text
Y_STN3m_i = alpha
          + delta * STNTargetScore_ind_norm_i
          + beta  * Y_Preop_i
          + error_i
```

Sensitivity model:

```text
individualized-DWI-only
```

In that sensitivity model, `S_STN` and `w_STN,k` are learned from individualized DWI features inside each training fold.

## Validation

- Use fully nested leave-one-patient-out cross-validation.
- For the normative-guided model, normative target weights and selected targets must be learned without the held-out patient.
- For DWI-only sensitivity, target weights, target selection, and feature standardization must all occur inside the training fold.
- Compare against covariate-only prediction and against the normative-only model.
- Report DWI coverage, target missingness, LOOCV prediction metrics, and agreement with the normative target pattern.

## Downstream Visualization

Export:

```text
DWI target coverage tables
C_ind_STN_bilat matrices
STNTargetScore_ind_norm.csv
STNTargetScore_ind_only.csv
individualized-DWI selected-target fiber subsets
coverage-weighted group STN seed voxel maps
```

Group STN voxel maps are generated by warping patient-specific DWI target-derived maps to template space and averaging with voxel coverage weights. They are consistency maps, not the main anatomical figure.

## Interpretation Boundary

This model tests patient-specific expression of an STN target-connectivity pattern. It is more individualized than the normative model but is limited by DWI quality, registration, and tractography coverage. Low-coverage targets should not be interpreted as negative biology.
